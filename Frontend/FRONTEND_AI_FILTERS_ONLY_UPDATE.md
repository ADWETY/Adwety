# Frontend AI Filters Only Update

تم تعديل الفرونت بحيث يكون دور الـAI داخل الفلاتر والبحث الذكي فقط، وليس كميزة مستقلة في الداشبورد.

## تم التنفيذ
- حذف ملف صفحة ماسح الروشتات القديمة `PrescriptionScannerPage.jsx` لأنه غير مطلوب كصفحة في الداشبورد.
- التأكد من عدم وجود Route أو Sidebar item لماسح الروشتات أو ماسح الكاميرا.
- إبقاء فكرة الذكاء داخل الفلاتر فقط باسم واضح للمستخدم: Smart Filter / فلتر ذكي.
- إضافة فلتر ذكي في صفحة الأصناف Products يدعم أمثلة مثل:
  - low stock / مخزون منخفض
  - out of stock / غير متوفر
  - no barcode / بدون باركود
  - profitable / مربح
- إضافة فلتر ذكي في صفحة الأدوية Medicines يدعم أمثلة مثل:
  - low stock / مخزون منخفض
  - out of stock / غير متوفر
  - available / متوفر
  - cheap / رخيص
  - expensive / غالي
- تعديل التسمية العامة من AI إلى Smart filters / الفلاتر الذكية.

## ملاحظة
لم يتم حذف أي API للـAI من الخلفية لأن المطلوب أن يظل متاحًا للفلاتر والبحث الذكي فقط.
