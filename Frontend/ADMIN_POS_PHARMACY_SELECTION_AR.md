# نقطة بيع الأدمن المرتبطة بالصيدلية

أضيف اختيار صيدلية موحد أعلى جميع صفحات البيع والمخزون الخاصة بالأدمن.

- لا تُحمّل بيانات المخازن أو الأصناف أو العملاء أو الموردين أو الفواتير قبل اختيار الصيدلية.
- تُرسل الصيدلية المختارة تلقائيًا مع كل طلب Retail في `X-Pharmacy-ID`.
- لكل صيدلية Cache مستقل لمنع اختلاط البيانات.
- تغيير الصيدلية يعيد تهيئة الصفحة والسلة والنماذج والفلاتر.
- جميع عمليات الحفظ تُرفض من الفرونت والباك إذا لم يختر الأدمن صيدلية.
- حساب الصيدلي لم يتغير؛ يظل مرتبطًا بصيدليته المسجلة تلقائيًا.
