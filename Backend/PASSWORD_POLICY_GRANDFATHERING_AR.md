# تعديل توافق كلمات مرور المستخدمين الحاليين

## الهدف
السماح للحسابات الموجودة بالفعل في قاعدة البيانات بتسجيل الدخول بكلمة المرور الحالية، مع تطبيق سياسة كلمات المرور القوية على الحسابات الجديدة وأي كلمة مرور يتم تغييرها أو استعادتها بعد التحديث.

## السلوك بعد التعديل

- المستخدم الموجود مسبقًا ولا يحتوي سجله على `passwordPolicyVersion` يُعامل كحساب قديم بالإصدار `1`.
- كلمة المرور القديمة الصحيحة لا تمنع تسجيل الدخول، ولا يُجبر المستخدم على تنفيذ OTP لمجرد أن كلمة مروره قديمة.
- إذا كانت كلمة المرور القديمة تحقق السياسة الجديدة، يعاد تشفيرها تلقائيًا إلى تنسيق الحماية الجديد ويصبح الإصدار `2`.
- إذا كانت كلمة المرور القديمة ضعيفة، يستمر تسجيل الدخول ويظهر تنبيه غير مانع يوصي بتغييرها من صفحة الإعدادات.
- الحسابات الجديدة تُنشأ دائمًا باستخدام `passwordPolicyVersion: 2` وكلمة مرور من 12 إلى 128 حرفًا.
- تغيير كلمة المرور أو استعادتها أو تعيينها من لوحة الأدمن يرفع الإصدار إلى `2` ويلغي الجلسات القديمة وفق آلية الأمان الحالية.
- MFA للأدمن ما زالت إلزامية ولم يتم تجاوزها أو تخفيفها.

## تعديلات الباك

- إضافة `passwordPolicyVersion` إلى نموذج المستخدم، والقيمة الافتراضية للحسابات القديمة هي `1`.
- إزالة الحظر `PASSWORD_UPGRADE_REQUIRED` من تسجيل الدخول.
- إضافة `password_upgrade_recommended` و`password_policy_version` إلى استجابات الحساب والملف الشخصي.
- تطبيق الإصدار `2` على كل مسارات إنشاء المستخدمين وتغيير كلمات المرور.
- إضافة اختبار `security:grandfathering-check` ضمن `security:check`.

## تعديلات الفرونت

- قراءة حالة سياسة كلمة المرور من استجابة الباك وحفظها داخل Session state فقط.
- عرض تنبيه ثنائي اللغة للمستخدم القديم مع زر للانتقال إلى إعدادات تغيير كلمة المرور.
- عدم منع الدخول أو تحويل المستخدم إلى استعادة كلمة المرور.
- تحديث إرشادات كلمة المرور إلى 12–128 حرفًا.

## التشغيل

داخل الباك:

```bash
npm install
npm run check
npm run security:check
npm run dev
```

داخل الفرونت:

```bash
npm install
npm run security:check
npm run build
npm run dev
```

لا يحتاج التعديل إلى Migration إلزامي؛ الحسابات التي لا تحتوي على الحقل الجديد تُعامل تلقائيًا كحسابات قديمة. يمكن إبقاء ملف `.env` المحلي الحالي كما هو.
