# اختيار الصيدلية في نقطة بيع الأدمن

تم تحويل وحدات البيع والمخزون الخاصة بالأدمن إلى مساحة عمل مرتبطة بصيدلية واحدة في كل مرة.

## آلية العمل

1. يحمّل الفرونت قائمة الصيدليات النشطة أو المعتمدة من لوحة الأدمن.
2. يختار الأدمن الصيدلية قبل فتح بيانات البيع والمخزون.
3. يرسل الفرونت معرف الصيدلية المختارة في الهيدر:

```http
X-Pharmacy-ID: <MongoDB ObjectId>
```

4. يتحقق الباك إند من أن الصيدلية موجودة وحالتها `active` أو `approved`.
5. تُشغّل جميع استعلامات نماذج المتجر داخل Tenant خاص بهذه الصيدلية فقط.
6. في حالة عدم إرسال الصيدلية، يرفض الباك الطلب بالكود `RETAIL_PHARMACY_REQUIRED`.

## المسارات

- المسار الأساسي: `/api/v1/retail/*`
- مسار الأدمن البديل: `/api/v1/admin/retail/*`

كلا المسارين يطبقان نفس عزل الصيدلية. لا توجد عمليات بيع أو مخزون عامة غير مرتبطة بصيدلية.
