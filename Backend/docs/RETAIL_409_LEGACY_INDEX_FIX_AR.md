# إصلاح خطأ 409 وعبارة code already exists في لوحة البيع

## سبب المشكلة

قاعدة البيانات القديمة كانت تحتوي على فهارس فريدة عامة مثل `code_1` و`name_1` و`number_1`.
بعد إضافة عزل بيانات كل صيدلية أصبح الصحيح أن تكون الفهارس مركبة، مثل:

- `pharmacyId + code`
- `pharmacyId + name`
- `pharmacyId + number`

وجود الفهرس القديم `code_1` كان يمنع إنشاء المخزن الافتراضي `MAIN` للصيدلية الثانية، ولذلك كانت كل طلبات لوحة البيع تنتهي بالحالة `409`.

## ما تم تعديله

- اكتشاف وحذف أي فهرس فريد قديم لم يعد معرفًا في مخططات Mongoose الحالية.
- الحفاظ على فهرس `_id` وكل الفهارس المركبة الخاصة بالصيدلية.
- إعادة إنشاء الفهارس الصحيحة تلقائيًا عند تشغيل الباك.
- إعادة المحاولة تلقائيًا مرة واحدة إذا ظهر خطأ فهرس قديم أثناء تجهيز بيانات الصيدلية.
- إضافة ذاكرة مؤقتة لمدة خمس دقائق لتجنب تنفيذ عمليات تجهيز البيانات الافتراضية مع كل طلب GET.
- تحويل رسائل التكرار في الفرونت إلى رسائل عربية واضحة.

## التشغيل

أوقف الباك ثم شغله من جديد:

```powershell
cd Backend
npm ci
npm run dev
```

سيظهر في الترمينال عند وجود فهارس قديمة سطر مشابه:

```text
Removed obsolete retail indexes: store_warehouses.code_1
```

ويمكن تنفيذ المزامنة يدويًا أيضًا:

```powershell
npm run retail:migrate-tenancy
```
